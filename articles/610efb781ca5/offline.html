Inside the CAW Riddles..

A Forensic Reconstruction..

Origin of the Hunt-
Every story leaves footprints.
CAW’s trace begins with a funding chain linking back to Shiba Inu (SHIB)’s creator.
On June 15 2021, the SHIB deployer wallet sent 2.78 ETH to an intermediary address.
303 days of silence followed…
Then on April 14 2022, that intermediary forwarded 2.22 ETH into a fresh CAW deployer address. Just 2 minutes and 20 seconds later, that very address deployed the CAW token contract, renouncing control immediately after.

The flow was deliberate..

This on-chain receipt trail was public for anyone to see — 
SHIB → intermediary → CAW deployer → CAW.
Such a clean lineage is not coincidence, it’s the puzzle’s first clue.
On-chain, what stands out is the transaction structure more than any personality or story, there’s an intermediary step in the flow that creates separation at a glance, but it still leaves a clean, followable trail for anyone willing to trace it end-to-end. That’s a factual pattern — indirection plus traceability — and it matters because it’s the difference between “a rumor you can argue about” and “a chain of receipts you can verify.” Pair that with the timing and the unusually deliberate-looking ETH values, and the most defensible way to frame it is simple, the trail was engineered to be missed by casual observers but recoverable by serious hunters —
a breadcrumb path that doesn’t require trust, only verification.
Equally telling is how CAW actually launched, not a hush-hush whitelist “presale,” but a public CopperLaunch / Balancer V2 Liquidity Bootstrapping Pool that ran April 14–17, 2022, seeded with about ~466.67T CAW and 1.8 ETH — meaning price discovery and early distribution happened in the open, on-chain, where anyone could show up and buy, and everyone could audit the flow afterward.
What’s still unusual (and rare) is what the contract doesn’t appear to give its deployer, in the captured probes, the proxy admin slot and implementation slot read as 0x0, and delegatecall is flagged false, which cuts against the common “we’ll upgrade later” control surface that so many launches quietly keep in their back pocket.
Plus the deployer’s behavior around launch looks consistent with a “deploy-and-step-back” posture — no recorded pre-launch activity, then funding and deployment actions clustered around launch day, more like a one-time ignition than an operator gearing up to manage a project.
and then came the riddles…
The mysterious CAW token deployer wallet (0xbaeEDcCcbFB112d4a921dAa635AC2276307A1705) embedded the starting keys for two elaborate riddles directly onto the Ethereum blockchain. Each clue came in the form of a self-addressed transaction with symbolic values and a short data payload:
Transaction 1 — May 9, 2022: TXID

https://etherscan.io/tx/0xfbbcf5338b4a9c35073ac7253afc1a8ee81770d8d3285b80497bbd9c2186ed5b

0xfbbcf5338b4a9c35073ac7253afc1a8ee81770d8d3285b80497bbd9c2186ed5b, from the deployer to itself carrying 0.666 ETH (with gas deliberately ~66.67% consumed) and input data 58bZfQ1. This “666” motif (two-thirds gas = 66.67%) nods to the “number of the beast” and inversion theme – indeed 0.999 in the next clue is 0.666 upside-down.
Transaction 2 — July 17, 2022: TXID
https://etherscan.io/tx/0xcae4b15350b3ccc2b37fec5caa718560241ec181bc49741d5d1199d1d32412d4
0xcae4b15350b3ccc2b37fec5caa718560241ec181bc49741d5d1199d1d32412d4, again self-sent by the deployer with 0.999 ETH (also ~66.67% gas used) and input zrUfKaKV. As expected, 999 mirrors 666, reinforcing a duality theme.
same signature
same author
Both transactions’ full hashes, values, and payloads were public on-chain – an immutable trailhead proclaiming the riddles’ legitimacy (coming from the token’s creator) and inviting the cawmmunity to investigate.
so we did…
and each hex data string turned out to be a key for an external resource.
Interpreted as UTF-8, 58bZfQ1 and zrUfKaKV weren’t random gibberish but rather slugs/IDs for content on the web.
In fact, the deployer was effectively saying “go to these addresses.” 
The first pointed to an image link; the second to a Pastebin page.

58bZfQ1 aka Riddle 1 (R1):

“Epic of Gilgamesh” Image — Hidden Poems, Coords, the Manifesto, and more
Transaction 1 — the real payload was in the Input Data field,
 an alphanumeric string 58bZfQ1. No explanation, just that string.
The community’s first test had arrived.
Within hours the CAW community proved its mettle. Telegram handle @KimDamyun ( a member of the cawmmunity and og riddle hunter in 2022) recognized 58bZfQ1 as a possible ImgBB image code (the format looks random but is short, fitting an image ID). Sure enough, visiting ibb.co/58bZfQ1 revealed an image – the first riddle image…
This image itself contained more hidden content.
Cawmmunity members quickly discovered that the 7-character string from the 0.666 ETH transaction fit at the end of an Imgbb URL. Indeed, 58bZfQ1 led to an image on ibb.co, https://ibb.co/58bZfQ1, titled..
“Proposal for a decentralized coup for teh ppl by teh ppl”.
This picture (640×776 PNG) showed a photograph of the Yale tablet of the Epic of Gilgamesh – a clear hint at ancient Mesopotamian lore
By 1:30 AM the next day (May 10), hunters had found the original image here:
https://www.gutenberg.org/files/11000/11000-h/11000-h.htm
then noticed there was a copy of the image super imposed on top and a secret message embedded steganographically in that image.
that secret message was the word “The” visible in one corner. The odd overlay of the word “The” suggested the image itself contained an embedded message.

A SHORT description of the gods and of other persons and places mentioned in the Epic will be found in this 
Glossary. The gods were credited at different times with a variety of attributes and characteristics, sometimes

reference to this description is given at the end of the Glossary note. Cross-references to other entries in the Glossary are

AD AD: Storm-, rain-, and weather-god. 

ANUNNAKI; Usually gods of the underworld, judges of the dead and offspring of Anu. 

ANSHAN: A district of Elam in south-west Persia; probably the source o£ supplies of wood for making bows. 
Gilgamesh has a bow of Anshan'. 

ANTUM: Wife of Anu.

An IPFS hash is a content-addressed identifier — in this case pointing to a file stored on the decentralized IPFS network. When resolvers fetched that hash, it downloaded a file: specifically, a .ape audio file (Monkey’s Audio format).

Fetching the data behind that CID yielded a packaged payload (the solver downloaded a small ZIP file). 
Inside were two files:
first_riddle_song.ape and first_riddle.txt.
The .ape file name “Tre rebus musicali” (Italian for “Three musical riddles”) was itself a clue. An .ape is an audio file (Monkey’s Audio format), suggesting the next layer was audio steganography.
Sure enough, using the tool DeepSound (which can hide files in audio) to inspect first_riddle_song.ape revealed it was concealing an embedded text file – but required a password to extract. The hidden file was named enkidu.txt, which hints at the password: “only the king’s lover has ears to hear” – in the Epic, Enkidu is the close companion of Gilgamesh. Using “enkidu” as the password, solvers unlocked the hidden text file via DeepSound.

Inside enkidu.txt was yet another encoded string – a lengthy hex sequence, but curiously it contained letters beyond the usual 0-9 and a-f. In fact, letters U through Z appeared in place of A–F, evidently a simple substitution cipher on the hex digits. Once the team mapped U→A, V→B, … Z→F and then heeded the poem’s last advice (“walk backwards”) by reversing this hex string, the result could be decoded as ASCII and then themanifesto was born...
